# Система управління книжковим каталогом (Book Catalog)

Комплексний веб-застосунок для керування бібліотекою книг. Розроблений на **Spring Boot** з використанням гексагональної архітектури.
Проект включає виконання лабораторних робіт **№4-7**.

## 🚀 Функціонал

* **CRUD Книг:** Перегляд, додавання, редагування списку книг.
* **База Даних:** Зберігання даних про книги (Назва, Автор, Рік видання, Опис) у H2 Database.
* **Email Сповіщення (Lab 7):** Автоматичне надсилання HTML-листа адміністратору при додаванні нової книги через **Gmail SMTP**.
* **Шаблонізація листів:** Використання **FreeMarker** для генерації динамічних листів.
* **Інтернаціоналізація (i18n):** Підтримка інтерфейсу українською та англійською мовами.

## 🛠 Технологічний стек

* **Java:** 21
* **Framework:** Spring Boot 3.2.1
* **Build Tool:** Maven
* **Web:** Spring MVC, Thymeleaf
* **Email:** JavaMailSender, FreeMarker
* **Database:** H2 (Embedded)
